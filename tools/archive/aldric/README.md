# Retired Aldric authorship

Original offline part-based authors and their side-walk test are retained solely
as history. They are not active build entry points and their original paths and
imports describe the retired layout. Do not run them to produce current assets.
Use `tools/build_regent_iselin.py` for complete current scene drawings and the
[global sprite standard](../../../docs/SPRITE_ANIMATION_STANDARD.md).
