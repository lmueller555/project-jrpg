# Daisy's single play bone — approved

A warm ivory 8×4 horizontal bone with rounded ends, restrained shading, and
vertical/diagonal variants. The new four-color palette is local to this prop;
it does not modify Daisy's original palette. `bone.json` records each image,
its center anchor and retained source layer. Initial floor center is [138,259].
The bone is nonblocking and represents one movable object rather than a
separate copy for every animation. Body actions and overlays live in
`assets/characters/daisy/bone_play/`.

Rebuild with `python tools/build_daisy_bone.py`.
