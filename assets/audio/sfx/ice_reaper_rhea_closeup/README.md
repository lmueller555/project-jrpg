# Rhea close-up ice pressure

`ice_creak.ogg` is a quiet, lower-pitched and filtered derivative of the existing
`../ice_reaper_rescue/prison_crack.ogg`. The retained MIT source libraries and
license files are documented in that package. No new recording or music is used.

The cue plays at 15.45 seconds, at gain 0.12, during Rhea’s closed-eye hold. The
score continues at its original speed. Awakening, prison burst and rune bloom
move one second later with the extended shot.

Rebuild from the repository root:

```sh
python3 tools/build_rhea_closeup_audio.py
```

`manifest.json` records the exact source hash, filter and derived-file hash.
