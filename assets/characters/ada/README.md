# Ada — child sprite pack

Age 7; Dark bob, blue dress and cream collar. Home: `home_b`.

Four directional idles, walks (4×140ms) and runs (4×100ms) use 24×36 frames
with foot anchor [12,34] and draw anchor [12,30]. Visible idle height: 24 px.
Original cast remains unchanged. Source layers/recipe retain every export.
Run poses use a forward lean, compact bent arms, alternating support/flight
and a lifted skirt; walks use the established one-pixel head/shoulder bob.

Rebuild with `python tools/build_schoolgirls.py`.
