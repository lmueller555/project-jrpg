# Bundled interface fonts

Gameplay and menu text use Atkinson Hyperlegible Regular and Bold, designed by
Applied Design Works for the Braille Institute. Their letterforms distinguish
commonly confused characters such as I/l/1 and O/0. UI text is rasterized at its
actual display size with antialiasing, independently of pixel-art world scaling.

The original, unmodified font files were downloaded from the Google Fonts
repository on 2026-10-25:

- https://raw.githubusercontent.com/google/fonts/main/ofl/atkinsonhyperlegible/AtkinsonHyperlegible-Regular.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/atkinsonhyperlegible/AtkinsonHyperlegible-Bold.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/atkinsonhyperlegible/OFL.txt

DejaVu Serif remains available for the approved game logo. Its original license
is included in `LICENSE-DejaVu.txt`. Bundled DejaVu Sans supplies individual
symbols omitted by Atkinson, such as arrows and check marks; baseline-aligned
fallback uses actual glyph coverage rather than an operating-system font.
