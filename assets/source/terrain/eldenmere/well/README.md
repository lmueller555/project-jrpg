# Well — retained source

`concept.png` is the generated appearance reference, retained at its original resolution and transparency. `recipe.json` records the native frame/registration, palette source, well footprint, water region, rounded plaza rows, paving instances, southern connection, drawing approach and gathering reservation.

`tools/build_eldenmere_well.py` thresholds alpha, samples nearest-neighbor at 72×90, registers it inside 84×96 and restricts materials to the existing cottage stone, timber, iron, slate, moss and water ramps. `parts/native_structure.png` and `parts/water_mask.png` retain the native appearance and the only pixels allowed to animate. No approved source building, terrain pack, character or story file is regenerated by this exporter.

The rounded square is an additive runtime-layout overlay. The original approved foundation plan is preserved, and the new layout/navigation records live in `assets/maps/eldenmere/well_square/`. Status is supplied by the recipe and is currently awaiting user review.
