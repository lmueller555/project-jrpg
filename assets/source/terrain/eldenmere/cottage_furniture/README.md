# Eldenmere cottage furniture source — review

The first reusable set contains an approved single bed with a cream pillow and folded sage patchwork quilt, an approved worn plank table, and a refined wooden chair in four directions awaiting review. The bed and table sprites, source samples and room positions remain byte-identical to the approved designs. Their orthographic top-down projection matches the approved cottage interior. Furniture stays fixed while the approved room daylight cycles.

`furniture_concept.png` is the generated source sheet, retained independently of its original workspace copy at `/workspace/generated_images/exec-e7940935-c1cb-4640-bdc6-b4e354f3eb31.png`. The approved interior room was supplied as a visual reference. No existing character, story, interior shell or outdoor artwork is modified.

`chair_directions_concept.png` retains the new four-direction chair source, originally `/workspace/generated_images/exec-e1ebdd19-5548-4eac-b69d-5dc7aae885fe.png`. The earlier furniture board supplied the visual reference. The revised chair has an 18px-wide, shallower seat, thinner front edge and slimmer legs. Down, up and left are extracted from this source; right mirrors the native left sprite for consistent construction. Direction means the direction a seated person would face: the up view shows the back of the chair. These are static facings, not a turning animation.

`recipe.json` records source crop rectangles, nearest-neighbor native sample sizes, transparent frame registration, per-asset approval status, the ten-color export palette and illustrative placements. Magenta is removed with the same explicit chroma rule as the interior source pipeline (red >160, blue >120, and both > green+70); surviving samples map to the nearest named RGB color. Chairs use only the existing wood ramp and outline. Exported sprites use binary alpha. There is no smoothing or runtime resizing.

The bed's visible source sample is 32×60 inside a 48×72 frame and the table 48×38 inside 48×48. All four chairs use 24×36 frames with a shared baseline at y=34. Native samples are 18×30 down, 18×27 up, and 18×31 left/right; the up view is shorter because the seat is hidden behind the backrest. Frame padding is transparent. The default `chair.png` filename aliases the revised `chair_down.png`. Terrain uses the 24px grid; 24×36 Caelan remains unchanged. `floor_rect` values describe suggested local floor occupancy for future placement, not implemented engine collision.

The furnished scene reuses the approved 288×288 expanded separate room, structure and all nine lighting overlays without rewriting them. Furniture is kept outside a 72px-wide central corridor from the south entry to the north door. The up-facing chair sits below the table. The down-facing chair is below the bed; the left/right views are along the lower left for comparison. These are illustrative art-review placements, not a named household or final level. Draw order is structure, approved daylight, furniture, original Caelan. Existing projected light does not intersect the furniture.

Build with `PYTHONDONTWRITEBYTECODE=1 /workspace/.venvs/project-jrpg/bin/python tools/build_eldenmere_cottage_furniture.py`; check with the same interpreter and `tools/test_eldenmere_cottage_furniture.py`. The builder retains native parts both here and in the runtime pack and creates a lossless 4× looping scene plus a 6× component board. The loop retains the approved 5.4-second timing; GIF encoding may combine held frames.

The bed and table are approved. The revised chair and its four facings await review. Sitting/sleeping poses, interactive furniture, household layouts, engine collisions, cupboards, shelves and hearth animation are future milestones.
