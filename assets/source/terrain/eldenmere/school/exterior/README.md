# Schoolhouse source layers

The reproducible builder is `tools/build_eldenmere_school_exterior.py`.
`recipe.json` records registration, material sources and native roof courses.
The layers directory retains fixed structure components. Smoke, lantern and
book-sign directories retain the eighteen individual animation layers.

Compose the ordered paths in each `school.json` source frame to reconstruct
its runtime image exactly. The smoke and lantern sample the existing approved
cottage layers without changing those source packs.
