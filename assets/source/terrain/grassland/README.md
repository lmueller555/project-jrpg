# Grassland source artwork

Place the downloaded `pixel_art_meadow_tileset_spritesheet.png` in this directory.

This folder stores **reference/source artwork**, not game-ready sprites. Before using any artwork in the game, validate exact 32×32 pixel regions, clean edges, tile seams, and mappings for the canonical 47 grass-to-dirt transition masks. Approved atlases belong in `assets/atlases/terrain/` and their semantic asset IDs in `assets/manifests/assets.json`.

Do not assume that the downloaded concept sheet has uniform tile boundaries or that its illustrated cells are in canonical mask order.
