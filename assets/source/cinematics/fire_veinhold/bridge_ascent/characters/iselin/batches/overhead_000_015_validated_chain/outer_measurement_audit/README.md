# Independent source-size audit

This directory contains read-only source crops, source pixel rulers and manually
observed boundary overlays. JSON records bind every measurement to the exact
source SHA, source cell and current production scale. No raw master, exported
PNG, registration or profile was changed.

`outer_cranium_observations.json` follows visible rounded attached hair-cap
boundaries rather than internal bright hair-whorl NCC windows. Those cap widths
are **exploratory hair-envelope observations, not proved rigid skull widths**.
For selected72, a wrapping windblown hair band enlarges the visible envelope;
QA's narrower core feature and this wider envelope refer to different features.
The cap-normalization arithmetic is retained for transparency but is explicitly
not a production recommendation.

`clasp_observations.json` independently cross-checks visible rigid appearance.
Within55–87 it measures the same whole beaded motif because a single central
sphere cannot reliably be resolved. Within88+ it separately measures the gray
inner pearl surface, excluding silver rim and white glint. These motif families
are not interchangeable. Small source pearls have20–25percent diameter
uncertainty, and angled motifs foreshorten. Jewelry/head proportions can also
drift within the painting independently of whole-figure density.

The clasp supports some56–71source-size/appearance growth, but selected72's
current rigid motif is close to frozen55. A large72rescale justified only by the
loose hair envelope is therefore not supported. Use multiple actual model
features and native continuity rather than replacing NCC-scale error with a
second unqualified ruler.

Sparse first/last samples do not establish one safe density for every source
pose. All proposed changes remain diagnostic and require parent model/native
review. No motion, anatomy or production acceptance is implied by these ruler
measurements.
