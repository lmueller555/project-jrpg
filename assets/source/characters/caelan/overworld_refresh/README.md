# Retired Caelan refresh bank

`assets/characters/caelan/scene_actions.json`, authored masters in
`../scene_actions_hd/` and `tools/export_caelan_scene_actions_hd.py`.

body exports have been retired. `../scene_actions_hd/retired.json` records their
hashes; needed prop/FX inputs were extracted before removal. Earlier visual
