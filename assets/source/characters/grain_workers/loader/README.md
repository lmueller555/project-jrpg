# Loader authored animation sources

Original image generations and exact prompts are retained here. The runtime
exports use whole authored bodies; there are no procedural arm lines, body
warps, or recolored pieces from the old front-only work poses.

The approved `male_02` idles and walks remain read-only references. Work and
carry frames use a 40×44 transparent canvas with foot anchor `[20,38]`; the
external grain sack follows each frame's registered palm contacts.
