# Retired Aldric artwork

These original runtime files were moved here when Iselin replaced the regent.
They are historical source evidence, not active assets or approved Iselin art.
Arrival, aerial and overworld folders retain the original PNG bytes. The old
portrait and seated pose are retained alongside them. Reference paths in Lucan
and clerk provenance now point here; their recorded image hashes are unchanged.
Original authoring scripts and the predecessor side-walk test are preserved under
`tools/archive/aldric/`, outside active builders and test discovery.
