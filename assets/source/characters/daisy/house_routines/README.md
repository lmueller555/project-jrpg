# Daisy house routine source layers

Generated by `tools/build_daisy_routines.py` from approved directional idle and
lying-pose layers. Each action directory retains four sets of transparent
feet/torso/head/ear/tail and face-detail layers. The runtime `house_routines/animations.json` records
layer paths, registration, mouth landmarks, timings and approved-source hashes.
Rebuild with the script; do not edit only the flattened runtime exports.
