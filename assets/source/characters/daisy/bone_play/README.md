# Daisy bone-play source layers

**Existing asset / legacy construction reference.** New or revised artwork
follows the [global sprite and animation standard](../../../../../docs/SPRITE_ANIMATION_STANDARD.md).
Part, mask, layer and registration recipes below document this pack's existing
implementation and reproduction, not the authoring method for new animations.
Approval records and original review evidence are retained.

Generated by `tools/build_daisy_bone.py` from approved dog idles, walks, lying
parts and the existing household pose helpers. Each action retains four sets
of body layers plus a separate bone overlay, including jaw/paw occlusion.
The runtime manifest records layer paths, exact mouth contacts, bone centers,
visibility, timing and approved source-image hashes.
