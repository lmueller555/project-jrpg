# Retired Regent quest runtime

**Status: Removed from current runtime.**

The old MQ03 relief visit, mining negotiation, secret crew, rescue and return-resolution quest have been removed from the running game. It no longer starts after MQ02, appears in Quest Playtests or supplies Gallery scenes.

The [approved replacement opening](narrative/game_01/CHAPTER_01.md) remains future story direction.
This retirement adds no Fire Veinhold prologue, invasion, new quest or initially
intact bridge. MQ01 and MQ02 remain playable with ordinary household and mill
framing; finishing MQ02 returns to exploration.

Historical review evidence remains in [the retained captures](reviews/mq03_resolution/README.md).
