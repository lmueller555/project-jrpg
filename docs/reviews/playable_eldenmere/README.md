# Playable Eldenmere review

These captures come from the actual Pygame runtime in `main.py`, using the checked-in runtime map and approved Caelan animations.

- `sanctuary.png`: initial spawn outside the sanctuary.
- `upper_bridge.png`: Caelan after running down the sanctuary stairs, along the workshop lane and across the upper bridge.
- `town_map.png`: the in-game map, with Caelan's live location and landmark legend.
- `gameplay.gif`: a short capture of that same movement and map overlay. Inputs advance the real player simulation at 60 Hz; the GIF samples approximately 15 frames per second at the default 2× pixel scale. It is a review capture, not a measurement of interactive frame rate.

Run `python main.py` to explore the whole town with WASD/arrows, Shift to run and M to view the map. Interiors, NPCs and quests are outside this first outdoor milestone.
