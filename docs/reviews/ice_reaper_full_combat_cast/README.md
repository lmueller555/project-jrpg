# Ice Reaper: full combat cast

[Watch the five-second preview](preview.mp4) or inspect [keyframes](keyframes.png).

All four party members now use approved combat art copied unchanged from assets/combat. Caelan, Mira and Lucan cycle their ready stances; frozen Rhea remains motionless. The renderer uses integer 2x display scaling and the combat manifests' foot anchors. Caelan starts already standing in the clearing because his combat set does not include a walking animation; the old cinematic walk frames and movement track have been removed from this scene. His original cinematic assets remain available to the opening cinematic.

Camera timing, dialogue, Rhea's prison and Wintermute2 are unchanged. Captured from the actual Gallery session at 30 fps. Music is reconstructed from the runtime OGG at the observed playback gain because SDL dummy audio has no loopback. See verification.json for capture details. This remains the first five seconds of the planned 45-second cinematic.
